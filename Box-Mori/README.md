# 📦BoxMori
Inspired web game from OMORI, except the characters are all small fun boxes!
## How to Use?
### **1. Download the Files or Copy the Code**
To use the code, you need to either download or copy in the files.
- Download the file/copy here listed here:
  1. [Box-Mori.html](https://github.com/ballanigue/HTML-Code/blob/main/Box-Mori/Box-Mori.html)
  2. [BM.css](https://github.com/ballanigue/HTML-Code/blob/main/Box-Mori/BM.css)
  3. [BM.js](https://github.com/ballanigue/HTML-Code/blob/main/Box-Mori/BM.js)
### **2. Open Sololearn here: https://www.sololearn.com**
NOTE: You may need to create your credentials before making the file
### **3. Paste All the Respective Codes in Each Language**
1. Paste Box.Mori.html text
2. Paste BM.css text
3. And lastly, paste BM.js text
### **4. Run the Code and You're Good To Go!**
Enjoy!
